# SDR Command Center Lite – skill download

This branch only holds the ready-to-install skill file. The source is on the `main` branch.

**Download:** [sdr-command-center-lite.zip](https://github.com/fehercsaba/sdr_command_center/raw/download/sdr-command-center-lite.zip)

## Install

1. Download the ZIP above (don't unzip it).
2. In your AI assistant's web app, go to **Customize → Skills → Upload skill** and choose the ZIP. Skills need code execution turned on (Settings → Capabilities).
3. Switch the skill on, start a new chat and say: **"Set up my SDR call desk – my company website is example.com."**
