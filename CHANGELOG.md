# Changelog – SDR Command Center Lite

Built by Csaba Fehér – https://www.linkedin.com/in/fehercsaba/ · optimised for Team plans

## 1.8.0
- Packaged as a plugin for the directory: the page ships as readable parts joined by the build script.
- License: PolyForm Shield 1.0.0. Privacy note added (the author collects no data).
- Leads: "Hide called" – hides leads already called while due callbacks and retries stay visible; remembered per person.
- Every person in the list has a copy-number button and a Script button that opens their call script right under the row (copy-number in call blocks too).

## 1.7.0
- Demo mode: a separate, fully populated fictional desk (180 leads, two weeks of calls, playbook, competitors, lists) that can be switched on and off; calls are never placed and nothing goes to HubSpot in demo mode.
- First open offers three starts: Set it up for me (auto-setup prompt), Explore with demo data, Quick start. Auto-setup is also reachable from the messaging step and the Setup hub.

## 1.6.0
- Safer storage: recovery when saved data can't be read (kept aside, restored from the newest daily copy), daily automatic copies (3 days), protected browser storage, backup date and a gentle reminder.
- Optional HubSpot write-back: calls and follow-up tasks, off by default, with a safe queue (no double logging, unclear results checked before any resend).
- UX, chosen by A/B comparison: slim counter outside Today, log right after you call, outcome buttons pinned on phones, quick start on the first setup screen, one-click import when key columns match.

## 1.5.0
- Optimised for Team plans: every account gets its own private desk, even in the same browser (a desk saved earlier stays with the page's owner).
- The company setup is readable by everyone the desk is shared with; only the owner and editors change it. Team members see a "Team desk" note and get updates with an Apply button.
- Imported originals and versions are stored per account.

## 1.4.0
- Setup hub: every answer with Edit links, the sources of the prepared setup, imported files with downloadable originals (last 10 kept).
- Start again: re-open the guide, re-apply the prepared setup, re-run auto-setup live, start from scratch (leads kept), reset everything.
- Versions (footer version number): what's new, plus automatic versions of setup, playbook and call script with restore and download.
- Re-runs on existing desks end with "Apply the new setup" instead of applying silently.

## 1.3.0
- Auto-setup with a live progress ring: past chats, website, competitors, playbook.
- Call-script generator per lead (quick look, call flow, two slots in their local time, objections, competitor reply, never-say list, AI-tailored opener).
- Competitors section in the playbook.

## 1.2.0
- Browser database storage for 20,000+ contacts, cross-tab sync, safe saving on close.
- "Active" view, more sort options, moving leads between lists on import, company website, column names in more languages.

## 1.1.0
- Read-only HubSpot import. Safer imports and exports. Many fixes.

## 1.0.0
- First release.
